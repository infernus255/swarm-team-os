# 29. Engineering Philosophy

Este documento actúa como contrato entre:

* Producto.

* UX.

* Ingeniería.

* QA.

* Arquitectura.

* Inteligencia Artificial.

El objetivo no es únicamente construir una solución funcional.

El objetivo es construir una solución:

* Correcta.

* Robusta.

* Escalable.

* Mantenible.

* Observable.

* Accesible.

* Fácilmente extensible.

Una solución que funcione pero sea difícil de mantener se considera incompleta.

Una solución elegante pero que no satisfaga las necesidades del usuario se considera incorrecta.

El éxito del proyecto se mide por la combinación equilibrada de calidad técnica, experience de usuario y capacidad de evolución futura.
